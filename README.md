# Semester Development Work

This repository is a starting point for my semester development work. It provides a simple, organised place to practise web development, keep track of changes, and build on the work covered during the semester.

## Current purpose

At the moment, the project is a basic HTML starter website. The first page is `index.html`. I will add features and improve the structure as the semester work progresses.

## Project structure

```text
semester-development-environment/
├── index.html
├── README.md
├── .gitignore
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── script.js
```

## Run the project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or API keys are required for this starter version.

## Git workflow

- `git status` shows which files have changed.
- `git add` stages the changes I want included in the next commit.
- `git commit` saves a checkpoint with a message describing the work.
- `git push` uploads local commits to GitHub.
- `git pull` downloads and integrates the latest changes from GitHub.

I plan to make small, clearly named commits so that the progress of the project is easy to follow.
